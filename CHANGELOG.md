## [Unreleased]

### Added
- **Apple Watch companion app** (#56): browse this week's sessions, session details and progress (PRs, recent workouts) on the watch; start a workout on the watch (HealthKit workout session: heart rate, calories, active time) with the same player as the phone: hero card, crown to adjust kg / reps, one-tap effort, rest ring with haptics, up next, pause / resume, summary. While the phone player runs, the watch mirrors it (set, rest countdown, next) and can complete sets, skip rest and add 15 s. Sets logged on the watch sync back to the phone (WatchConnectivity). New watchOS target (bundle id `<app id>.watchkitapp`, watchOS 10).
- **Faster logging in the workout player** (#55): current-set card with kg / reps steppers prefilled from the load suggestion (no keyboard); after each set a one-tap effort picker (Fail / 1 / 2 / 3 / 4+ reps left, logged as RIR) on the rest screen; gradient "Up next" card (next exercise with image, sets × reps) in the player and next set or exercise on the rest screen.
- **Live Activity** (#55): lock screen + Dynamic Island show the current set or rest countdown and what's next, with +15 s / Skip rest buttons; "Rest over" notification when the app is in the background. New widget extension target (bundle id `<app id>.LiveActivity`).
- **Pause and resume a workout** (#57): the player's pause button offers Pause (resume later at the same exercise, sets done and active time, also after closing the app), Finish & save now, or Discard. "Resume workout" on the session and week cards.
- **Workout library** (#62): Train's "My workouts" + "Example workouts" become one library: your workouts, built-in (Lowerbody, Arms + Shoulder) and workouts shared by members, as Explore-style gradient cards (All / Mine / Built-in / Members filters, search). From a workout's page: **Start workout** runs it as a standalone quick session; **Add to plan** replaces a day of this week's plan or adds an extra session (optional weekday), kept on a new variation, cleared on a week change, synced with the profile; planned ones can be removed again. Share your own workouts as Only me (default) / Members / Public, same model as Community (#61); members' workouts show the author, can be saved as a private copy, reported (auto-hidden after 3 reports) or their author blocked. API: `visibility` on `/v1/me/custom-workouts` (needs community profile, text filter), `GET /v1/library/shared`, `/:id`, `/:id/save`, `/:id/report`; migration adds `visibility`, `shared_at`, `hidden_at`, `saves` to `custom_workouts`. Demo screens `library`, `library-plan` in CI screenshots.
- **Notifications** (#69). Account → Notifications, Explore-style cards with toggle and time per type:
  - **Session reminder** on the morning of each planned session (default 07:30); tap opens the session.
  - **Missed session** check-in the next day (default 09:00) with **Train today** / **Pick another day** (moves it to the next free day via the training calendar, or opens the calendar). Cleared once the session is recorded.
  - **Your achievements** (#76): notification when you unlock a badge (Progress → Achievements); tap opens the badge. Own toggle.
  - **People you follow**: APNs push when they set a PR (PR attempts) or unlock a badge (sent once per badge; device announces new badges via `POST /v1/me/achievements`, old badges never sent). Followers come from Community follows (blocks respected); only members whose default visibility isn't private announce, shown by nickname. Tap opens their community page.
  - **Quiet hours** (default 22:00–07:00): local reminders move out of the window, remote pushes arrive silently.
  - Send test (local + server push). Reminders follow the training calendar's dated sessions (moves, days off, travel).
  - Backend: push device registry, notification prefs, APNs HTTP/2 token-auth sender, dead tokens removed; secrets `APNS_KEY_ID` / `APNS_PRIVATE_KEY` via **Fly setup**; skipped until set. Device unregistered on sign-out; data deleted with the account.
- **Training style** (#78): training profile → Rest between sets (long 2–3 min / standard / short 30–60 s) and Group exercises (straight sets / supersets of the same muscle group / circuits of 2–4 per body area). Goal defaults marked REC (Max strength, Explosive, Build & define: long rests; Build & define: supersets; Endurance: short rests + circuits); picking REC keeps following the goal. Generator honours both: main lifts stay straight with ≥ 90 s rest, grouped accessories labelled A1/A2 share the rest after the round and get extra rounds for the saved time (not in deload). Session cards show the group badge. Optional profile/plan fields, older data decodes unchanged.
- **Supersets and circuits in the workout player** (#78): grouped exercises play back to back, A1 → A2 with no rest, then the group's rest before the next round; after the last round the player moves on to the next exercise. Up next / rest screens show the next member or round.
- **Exercise coverage** (#77): 14 staples fill catalog gaps found in an audit (patterns with 1–3 options): Smith machine squat, barbell good morning, reverse nordic, TRX hamstring curl, leg press calf raise, incline barbell bench, pec deck fly, chin-up, band-assisted pull-up, close-grip bench, dumbbell overhead triceps extension, reverse crunch (grip-free core for climbers), Copenhagen plank (adductors), side-lying dumbbell external rotation (rotator cuff without a cable). Each has technique notes and media: 11 free-exercise-db photos (pinned, public domain), 3 new own illustrations. All generator-eligible (177 exercises).
- **Community tab** (#61): Train / Explore / Progress / **Community** / Account. Community profile with nickname, profile photo and short bio. Share a win (recent workout, personal best or badge) as a vivid card with caption; per post visibility **Only me / Members / Public** (public adds a web link `/share/:id`), default set in the profile (Only me unless changed); change or delete any time. Optional auto-share of finished workouts. Follow members; feeds: **Members**, **Following** and **Mine** (private progress log). Cheers on others' posts: ❤️ like, 💪 strong, 🔥 on fire, 👏 keep going. Member pages with shared wins and cheers count. App Store 1.2: community guidelines acceptance to join, objectionable-text filter (nickname, bio, captions), report post or member (mailed to `MODERATION_EMAIL` when set), post hidden after 3 reporters, block both ways, leave community deletes profile/photo/posts. Photos re-rendered on device (square, ≤512 px) and stripped of EXIF/GPS on the server. API `/v1/community/*`; included in data export and account deletion. Moderation helpers (`community/moderation.ts`) reusable for other shared items; `followerIds(db, userId)` for push fan-out.
- **Week to week** choice in the training profile (onboarding + Train → edit) (#64): **Same every week** (identical exercises per day all cycle, only sets/effort change), **Fresh each week** (default: main lift per day stays for progression, accessories/warm-up/mobility/cardio change weekly) or **Rotate muscle focus** (day order and each day's lead lift rotate weekly, same patterns and weekly volume). Explore-style gradient cards. Stored as optional `variety` in the profile (older profiles → Fresh). Main lifts now stay stable across weeks in every mode (previously re-rolled weekly). Train → New variation still reshuffles with a new seed. Demo screen `variety` added to CI screenshots.
- **Find a gym** (#70): gyms near you (location, when in use) or near a city/hotel/address, from Apple Maps (fitness centres, nearest first) on a map + list. Tapping one shows details in the app first: distance, address, map, phone (tap to call), website host, Directions (Apple Maps), Hours & photos (Apple Maps place card), then Open website. From Calendar (toolbar) and travel mode (Full gym nearby → "Find gyms near <place>", Use this gym). Demo screen `gyms` added to CI screenshots.
- **Training calendar** (#68): Train → Calendar shows this week and the next 5 with dated sessions, climbing days and cycle phase (Base/Build/Peak/Deload); tap a day for its session (exercises, sets × reps). **Can't train**: mark a date or range (optional reason); sessions move to free days of that week (climbing/spacing rules kept), with too few free days the week switches to the smaller split (fewer, fuller sessions), days left over are listed as skipped. **Travelling**: date range, place, and what's there (hotel gym, dumbbells only, bodyweight only, bands, full gym via Apple Maps search) + fine-tune equipment; sessions on those days are rebuilt for that equipment. Climbing days are paused while away. Current week: done sessions stay, only today onward is re-planned; Train shows travel days on session rows. Synced in the profile (`away`, optional, older profiles decode). `RescheduleSheet` / `AppModel.reschedule(sessionId:)` move a session to the next free day; `AppModel.plannedSessions(from:to:)` lists dated sessions (for reminders). 18 travel-kit exercises with full technique (bodyweight squat/split squat/lunge/single-leg RDL, single-leg hip thrust, table row, prone floor pulldown, pike push-up, single-leg calf raise, dumbbell bent-over row/floor press/standing press/floor pullover, band row/pulldown/chest press/overhead press/good morning), picked only when no barbell, cable or machines are available, so full-gym plans are unchanged. Travel exercises have media: 8 free-exercise-db photos (public domain) and 10 own two-frame illustrations (`ios/Tools/illustrations` now also reads `Exercises+Travel.swift`). Demo screens `calendar`, `away` added to CI screenshots.
- **Custom exercises** (#52): build your own exercise, e.g. for a machine in your gym, from **New exercise** in the Add exercises picker. Name, category, machine name, equipment, main/assist muscles on a body map, reps or seconds, up to 3 cues. Picture: a photo (camera or library, compressed to ≤300 KB) and/or a pose drawn in the **pose designer** (start/end frames, drag joints, templates, props such as seat, pad, cable, bench). - **Attempt a PR** (#60): exercise page → "Attempt a PR" (Library and from a session's exercise) for strength moves. Choose 1RM, rep max (3 or 5) or max reps (only option for bodyweight moves; load = added kg). Up to 3 attempts (made → +1 increment, missed → same load). Result screen celebrates a new record (+Δ vs previous best) and makes a shareable image card (1080 × 1350: exercise, load, +Δ, date, MonkeyWorkout) with caption text for Instagram, Messages, WhatsApp etc., PR history per exercise (long-press deletes). Made attempt sets are logged into the exercise history but ignored by load suggestions. Synced via API `/v1/me/pr-attempts` (in export and account deletion) for the upcoming community feed.
